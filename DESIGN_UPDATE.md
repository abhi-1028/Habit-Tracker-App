# Neon Momentum UI Update

This build applies the selected product direction:
- Dark & energetic
- Near-black background with subtle gradients/glows
- Controlled multi-color neon accents
- Moderate neon usage
- Hybrid solid/glass surfaces
- Moderately rounded components
- Clean futuristic typography
- Floating glass/neon navigation
- Smooth, subtle animations
- Futuristic Progress dashboard with dated Rhythm
- More reliable Unicode custom-icon storage
- Gallery-based profile pictures
- Functional daily goal, theme, notifications and compact-card preference
- More reliable note persistence
- Refreshed Android splash styling

Known limitation: Flutter SDK is not available in the packaging environment, so run `flutter pub get` and `flutter analyze` locally before testing.
